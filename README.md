# Tripora

A planned offline-capable travel companion for Android and iPhone, with shared trips,
places, food, nightlife, expenses and memories.

**Current stage: planning and structural scaffold. There is no runnable application yet.**

## Layout

- apps/mobile: future mobile application
- services/api: future backend
- tests/e2e: future cross-device acceptance scenarios
- docs: plan and project status

The stack remains a proposal until agreed. Dependency installation and implementation come next.
This directory is the clean restart; the parent project's old source and history are excluded.

Documentation workflow informed by [Bilal Ahmad's setup article](https://bilalahmad72.com/blog/vibe-coding-setup-files/).
All product requirements and architecture content here are written for Tripora.
