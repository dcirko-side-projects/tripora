# Tripora — funkcionalna provjera 2026-10-25

## Opseg i kriteriji

Korisnik je zatražio provjeru svake postojeće funkcionalnosti u petlji test → nalaz → popravak → regresijska provjera. Provjerava se trenutačni razvojni proizvod; hosting, nova autentifikacijska usluga i distribucija nisu dodani.

Kriteriji za dostupni automatizirani sloj:

1. Nema pada testova niti neobrađenih grešaka u provjerenim tokovima.
2. Validacija/odustajanje ne stvaraju zapise; spremanje/uređivanje/brisanje čuvaju očekivane lokalne podatke i redove.
3. Retry/izgubljena potvrda ne dupliciraju zapise ili iznose; sukobi čuvaju zadnji nacrt, a tombstone se ne oživljava.
4. Ovlasti se provjeravaju na stvarnom API-ju. Osobni packing i podaci drugog računa ostaju odvojeni.
5. Foto nacrt se može odbaciti; spremljena/referencirana slika se ne briše prije vremena; preuzimanje je eksplicitno.
6. Migracije/restart/povrat backupa čuvaju podatke; prekinuto preuzimanje ne označava cijeli metapodatkovni snapshot kao dovršen.

Za završni native prihvat dodatno treba stvarni uređaj i instalirani build. Na ovom računalu nije pronađen adb ni Android SDK u standardnoj lokaciji/varijablama, niti je dostupan iOS simulator. Nije provedeno upravljanje korisnikovim mobitelom. Testovi native komponenti koriste mockove; taj sloj se ne proglašava fizički provjerenim.

### Ispravak 1: valuta nakon brisanja

Reprodukcija: EUR budžet → trošak → brisanje zadnjeg troška → Uredi budžet. UI je omogućavao USD/GBP jer je gledao samo žive troškove. Postojeće pravilo i baza već zaključavaju valutu nakon bilo kojeg troška, uključujući obrisane. UI sada provjerava i povijest/tombstoneove; pravilo, API i baza nisu mijenjani.

Regresija: `budget UI: currency stays disabled after deleting the last expense` u `apps/mobile/tests/featureUi.test.cjs`.

### Ispravak 2: native dijeljenje pozivnice

Reprodukcija: izdana pozivnica → Podijeli kod → Share.share odbije Promise. Prije je ostajala neobrađena greška. Sada modal prikazuje poruku, čuva izdani kod i omogućuje kopiranje dugim pritiskom. Otkazivanje native share dijaloga nije tretirano kao uspješna dostava drugoj osobi.

Regresija: `membership UI: failed native sharing is handled without losing the issued code`.

## Otvoreni uvjeti za završetak faze 1

### Priprema fizičkog Android testa

Korisnik je odobrio lokalnu instalaciju službenih Android SDK alata i prihvat licence. Povezan je i autoriziran Samsung Galaxy S25+ (SM-S936B), Android 17/API 37. SDK i JDK 17 nalaze se u ignored `local-data/`; nije mijenjana globalna Java instalacija.

Izolirana kopija izvora u `local-data/native-qa` gradi zasebni paket `local.tripora.qa` (Tripora QA). Kriterij prvog prolaza: instalirani paket otvara se bez Metroa, sintetički račun može se registrirati i zapisati putovanje, a nakon prekida API veze i ponovnog otvaranja sesija/podaci i novi lokalni rad ostaju sačuvani. Tek zatim slijede preostali native tokovi iz matrice.

QA koristi HTTPS preko USB prosljeđivanja na lokalni API. Jedinstveni kratkotrajni lokalni certifikat pouzdan je samo za localhost u tom QA paketu; nije instaliran u sustav laptopa ili telefona. Produkcijska HTTPS provjera i konfiguracija izvornog projekta nisu oslabljene. Lokalni APK koristi razvojni potpis, nije distribucijski release. Instalacija je potvrđena; funkcionalni rezultati zasad su PENDING. Sama ADB veza nije dokaz prolaza. iPhone trenutačno nije dostupan.

Samostalni arm64 APK uspješno je izrađen (`assembleRelease`, 383 zadatka). Paket `local.tripora.qa`, verzija 0.1.0/1, target SDK 36, uključuje Hermes JS bundle od 1.670.648 bajtova. APK SHA-256: `1c9d82f71cf42d547d95e77b15dfb09bbe9c86eb384d098ea0a08c68fd980db2`. Instalacija preko USB-a vratila je `Success`; `am start -W` potvrđuje pokrenuti `local.tripora.qa/.MainActivity`, a proces je prisutan. Funkcionalni fizički test ostaje PENDING. Provjera lock screena vraća `showing=true`; korisnik je zamoljen otključati telefon i provjeriti instalacijski upit. Ne zaobilazimo zaključavanje niti mijenjamo globalne sigurnosne postavke.

Nije opravdano proglasiti puni native prihvat završenim. Preostaju stvarni Android/iPhone: instalirani build bez Metroa, hladni start u airplane modeu, SecureStore/SQLite bridge, stvarna galerija/dozvole/codec i metadata, slab signal, nizak prostor, veliki tekst, čitač zaslona, tipkovnica i višekorisničko putovanje. Expo Go dostupnost nije isto što i samostalan instalirani build.
